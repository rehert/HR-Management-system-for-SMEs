# HR-Management-system-for-SMEs

A Python-based HR leave management system designed for small and medium-sized enterprises.

The system allows employees to submit leave requests and view their leave history, while HR can review requests, approve or reject them, and manage leave information.

## Features

- Employee leave request submission
- HR approval and rejection of requests
- Leave request history
- Leave balance tracking
- Separate Worker and HR interfaces
- Supporting document handling
- Basic HR leave administration

## Technologies Used

- Python
- CustomTkinter
- Tkinter
- CSV file handling
